# BetEA Logo Files

## Logo Concept

The BetEA logo features:
- **Rising arrow/chevron**: Symbolizes upward momentum, winning, and growth
- **Green color**: Trust, prosperity, and connection to M-Pesa (familiar to East African users)
- **Gold accent**: Winning moments, premium quality, success
- **Bold typography**: Confidence and strength

## Files Included

### Current SVG Files
1. `logo-concept.svg` - Full logo with tagline (for presentations)
2. `logo-icon-only.svg` - Icon only (for app icon, favicon)
3. `logo-horizontal.svg` - Horizontal layout (for website header)
4. `logo-white.svg` - White version (for dark backgrounds)

## Usage Guidelines

### Minimum Sizes
- **Digital**: 120px width (horizontal), 80px width (icon only)
- **Print**: 25mm width (horizontal), 15mm width (icon only)

### Clear Space
Maintain clear space equal to the height of the "E" in BetEA on all sides.

### Don'ts
- ❌ Don't stretch or distort
- ❌ Don't rotate
- ❌ Don't change colors (except approved variations)
- ❌ Don't add effects (shadows, gradients, outlines)
- ❌ Don't place on low-contrast backgrounds

## Notes for Designer

If you're refining these logos:
1. Ensure the arrow/chevron is perfectly centered
2. Maintain consistent stroke widths
3. Test legibility at small sizes (32px)
4. Ensure sufficient contrast for accessibility
5. Create a style guide with exact measurements
6. Export in multiple formats for different use cases
